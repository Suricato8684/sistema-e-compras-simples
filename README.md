🛒 Sistema de Compras – Calin

Sistema desktop de gerenciamento de compras desenvolvido em Python, utilizando Tkinter para a interface gráfica e SQLite3 para armazenamento dos dados.

O projeto tem como objetivo facilitar o cadastro e o controle de compras, permitindo registrar produtos, organizar categorias, calcular valores e acompanhar o total gasto.

📌 Funcionalidades
📝 Cadastro de produtos.
📂 Seleção de categorias.
🔢 Registro de quantidade e valor unitário.
🧮 Cálculo automático do valor total de cada compra.
📋 Listagem de compras cadastradas.
🗑️ Exclusão de compras.
🧹 Limpeza dos campos do formulário.
💰 Cálculo automático do total geral das compras.
💾 Armazenamento dos dados em banco de dados SQLite.
💻 Tecnologias utilizadas
Python – Linguagem de programação.
Tkinter – Desenvolvimento da interface gráfica.
SQLite3 – Banco de dados para armazenamento das compras.
🎨 Interface do sistema

A aplicação possui uma interface gráfica intuitiva, com formulário de cadastro, botões de gerenciamento e tabela para visualização das compras.

⚙️ Como executar o projeto
1. Pré-requisitos

Tenha o Python instalado em seu computador.

Download: https://www.python.org/downloads/

2. Clone o repositório
bash
git clone URL_DO_SEU_REPOSITORIO

3. Entre na pasta do projeto
bash
cd nome-do-repositorio

4. Execute o sistema
bash
python sistema_compras.py


Observação: O Tkinter e o SQLite3 geralmente já acompanham instalações padrão do Python. O banco de dados é criado automaticamente na primeira execução.
